# My Portfolio

A responsive personal portfolio website built with React and Tailwind CSS. It shows my education, projects and contact details as a Python fullstack developer.



## Features

- Responsive layout that works on mobile, tablet and desktop
- Education section with a card for each qualification
- Contact section with a direct email link
- Footer that stays at the bottom of the page
- Styled with Tailwind CSS utility classes only

## Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS, Tailwind CSS
- **Build tool:** Vite

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or later
- npm (comes with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/your-repo-name.git

# 2. Go into the project folder
cd your-repo-name

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open the local address shown in the terminal (usually `http://localhost:5173`).

### Build for production

```bash
npm run build
```

The output goes to the `dist` folder. To preview it locally:

```bash
npm run preview
```
